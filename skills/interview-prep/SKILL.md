## When to use this

Use this skill whenever the user:

- Mentions an interview.
- Mentions a coding assessment.
- Mentions a recruiter screen.
- Mentions a technical phone screen.
- Mentions an onsite interview.
- Mentions a behavioral interview.
- Mentions a system design interview.
- Asks for interview preparation.
- Requests mock interviews.
- Mentions a specific company interview.

## Instructions

1. Ask for the company name if it isn't already known.
2. Ask which role they are interviewing for.
3. Ask which interview stage they are preparing for.
4. Use `recall_similar_notes` to retrieve any previous interview experiences, questions, or preparation notes related to the company or role.
5. If previous notes exist:
   - Summarize them.
   - Highlight repeated questions.
   - Point out important topics.
6. If no notes exist:
   - Clearly state that no previous interview history is available.
7. Generate 3–5 interview questions appropriate for:
   - the company,
   - the role,
   - and the interview stage.
8. For each question:
   - Explain why it is asked.
   - Describe what interviewers look for.
   - Provide a strong sample answer or outline.
9. Recommend a short preparation plan covering:
   - core technical topics,
   - coding practice,
   - system design (if applicable),
   - behavioral preparation.
10. End by asking whether the user would like to start a mock interview.
